# Benchmark Results

Raw benchmark output belongs here when it is intentionally recorded. Each result
must identify the candidate, scenario, commit, operating system, device/CPU,
architecture, SDK/toolchain versions, build mode, library versions, and network
conditions. Do not commit favorable results without the complete methodology and
source scenario. Raw results retain individual samples; summaries retain median,
mean, p95, p99 where the sample count supports it, standard deviation, TTFB, throughput, and scenario-local
interpretations. There is intentionally no single overall speed score.
